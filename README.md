# 8LM-3

A responsive login page with username or email, password, required-field validation, and a password visibility toggle.

## Preview

Run `npm ci`, then `npm start` from this folder and open http://localhost:8000.

## Render

Create a Node Web Service from this repository using `npm ci` as the build command and `npm start` as the start command. The server uses Render’s `PORT` environment variable.

This is the login interface only. Account authentication requires a backend; the form currently displays an explanatory message and does not send or store credentials.
